2 · Guess, rule, loss, targets

moves 1–4: nothing changes yet

The guesser reads each image and spreads its bets across 10 digits. The rule turns the two guesses into chances for each sum and the loss scores the labeled sum. Then the rule works out what each guess should have been to explain that label: the dashed outlines.

3 · The weights

move 5: the only change

W is 64 pixels × 10 digits. Each tile is one digit's column of W laid back out as an 8×8 image: green pixels push the guesser toward that digit, orange push away. At step 0 it's noise. Run a few dozen steps and the tiles become digit templates.

W after this step

ΔW: what this step changed (all 32 pairs combined)

pA, pB = guess(model, xA), guess(model, xB) # 1. guess p_out = apply_rule(pA, pB) # 2. apply the rule loss = loss_fn(p_out, label) # 3. score against the label targetA, targetB = what_would_explain(pA, pB, label) # 4. work out the targets errA, errB = (pA - targetA) / n, (pB - targetB) / n # how far off each guess is model["W"] -= lr * (xA.T @ errA + xB.T @ errB) # 5. update weights <- ΔW above model["b"] -= lr * (errA.sum(axis=0) + errB.sum(axis=0))
